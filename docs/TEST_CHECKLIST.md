- [ ] `visualViewport`の高さ変更で戦闘画面が収まる
- [ ] 画面回転時に戦闘が停止し、再開できる
- [ ] 非表示から復帰しても黒画面にならない
- [ ] 長押し、二重タップ、指を戦場外へ出して離す操作が破綻しない
