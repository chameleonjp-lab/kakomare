## 対象

PR-Bでは、監査で残した「武器8種・補助6種の実効値」「分岐と補助の説明・動作差」「スマホの強化候補」「演出・音・時間・図鑑・結果画面」を実装した。

| 項目 | 対応 |
|---|---|
| 48組の補助適用 | 隣接面を基準にした8武器×6補助の表を追加。出力・律動・収束・観測・制動の上限を成分別に検査し、分岐環の重複は最短間隔を採用 |
| 分裂型 | 着弾後に3小弾を生成し、各小弾が別の着弾範囲を処理。子弾は再分裂しない |
| 強反発型 | 押し戻し距離に加えて一射の威力へ1.25倍を反映 |
| 制動環 | 反発輪、群集弾の残留領域、遠隔重力点の減速時間へ隣接効果を反映 |
| 時間表示 | 通常ステージは残り時間、無限モードは経過時間をスナップショットから表示 |
| 強化候補 | 320px/402px幅で縦積み、説明と変更値を読み上げ関連付け。新規装置は面を1回タップ |
| 結果・図鑑 | 全8武器の総与ダメージ、補助の接続状況、敵・ボスの説明と解除状態を表示 |
| 音 | カウントダウン、開始・再開・一時停止、被害、強化、ボス、撃破、勝敗を状態別キューへ分離 |

強化中は既存仕様どおり、戦闘時間と敵の動きを通常の10%へ落とす。候補を読む時間を確保しつつ、入力・演出の復帰境界を完全停止にしない判断を [GAME_RULES.md](GAME_RULES.md) と [TEST_CHECKLIST.md](TEST_CHECKLIST.md) に記録した。
