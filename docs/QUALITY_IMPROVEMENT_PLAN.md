# カコマレ 品質改善の進行計画

2026年9月8日の「カコマレ：監査と改善実装計画」に基づく作業記録。初回開発の `IMPLEMENTATION_PLAN.md` に対する追加の改善工程です。

監査基準と開始時の最新mainはいずれも `e6ca4229156819ccce8b47ef4273b2e0451d4d75`（PR #13）。開始時に監査後の差分と未処理のPRがないことを確認しました。

## 3本のPRと対応範囲

| 工程 | 対象 | 状態 |
|---|---|---|
| PR-A | 除外後の配置、面と接続線、照準・盾・吸引、終端破裂・崩壊の倍率、危険の最低描画、実戦の最小再現検査 | 作業中。詳細は [QUALITY_A_REPORT.md](QUALITY_A_REPORT.md) |
| PR-B | 武器8種と補助6種の実効値、残る分岐・補助不整合、スマホの強化候補、演出・音・時間・図鑑・結果画面 | 未着手 |
| PR-C | 本戦360試行、描画頻度による一致、ボス行動と手動照準、負荷・保存・復帰、実機確認と調整 | 未着手 |

各工程は1本のPRにまとめ、失敗した検査とレビュー指摘は同じブランチで直します。作業ブランチからDraft PRを作成し、ユーザーがmainへのマージを判断します。

既存の進行規則に従い、次のPRは前のPRがユーザーによってマージされた後に作成します。

## PR-Aの完了条件

| 監査項目 | 確認すること |
|---|---|
| A01 | 最後の除外後も新規武器・補助を1回タップで取得できる。除外、引き直し、配置の有効条件を分ける |
| A02 | 武器1→3→2・補助3→1→2の取得でも、空き面・隣接効果・表示・一時停止の一覧が一致する |
| A03 | 正負の角度境界と360度の加減で、照準・回転冠の盾判定が変わらない |
| A04 | 吸引の安全半径内外、境界、同位置、ボス、複数領域で座標と内部距離を一致させる |
| A05 | すべての演出設定で敵180体・敵弾80発を隠さない。装飾の軽量化と戦闘結果を分離する |
| A06の一部 | 座標軸上でも連鎖の終端破裂を出す。重力の崩壊にも生成時の攻撃倍率を適用する |
| A07 | 弾・反射光線・連鎖・範囲攻撃・周回刃の入射面を定義し、回転する盾の表示と一致させる |
| 検査 | 修正前失敗と修正後成功を記録し、既存検査・ブラウザ検査・本番ビルド・公開用静的検査を通す |

実戦検査では本番の戦闘処理を呼び出し、テスト用の別の戦闘計算は作りません。描画の代替を使う検査では、ブラウザやiPhoneの性能を保証しないことを明記します。

## PR-B・Cへ残す内容

- PR-B：反発輪の分岐、重力と制動環、周回刃と分岐環、光線と収束環などの効果を説明と一致させる。48組の補助適用表を整備する。
- PR-B：402×874・320×568・横画面・文字200%で候補を確認する。面を1回タップして取得する操作を維持する。
- PR-B：強化中の完全停止などは仕様変更として理由と採用内容を記録する。
- PR-C：通常3ステージ×開始値20種×選択方針3種×研究2段階の360試行を初期検査とし、勝敗・成長・ボスの最初の固有行動を記録する。
- PR-C：同じ開始値と操作を30・60・120回/秒の描画条件で比較する。例外、無限待ち、記録の二重加算を許さない。
- PR-C：iPhone 17 Pro・Safariで回転、中断復帰、指の操作、3回以上の再戦、音0・演出最小を確認する。通常60回/秒を目標、高負荷でも継続30回/秒以上を検証目標とし、達成済みとは扱わない。

判定修正後に旧版と勝率が変わることはあり得ます。勝率を戻すための一律の敵体力増加は行わず、PR-Cで修正後の同じ開始値・操作を比較します。名前、進行、購入済み研究、記録は引き継ぎます。
