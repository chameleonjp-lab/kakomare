# カコマレ ゲームルール

## 目的

中央のコアを守りながら、敵を倒して装置を育てます。ステージ1では最後に現れる回転冠を倒すと防衛成功です。コアの耐久力が0になると防衛失敗です。

## 操作

- 戦場を1本指で18px以上ドラッグすると、その方向を優先して狙います。
- 指を離してから0.8秒後に自動照準へ戻ります。
- 強化候補は1回タップで選びます。
- パソコンではマウスのドラッグとクリックを使います。Escで一時停止できます。

## 装置

初期装置は連針砲です。連針砲は単体への連続攻撃が得意です。強化候補から光路刃、群集弾、反発輪を追加できます。補助装置は左右に接続した武器へ効果を与えます。

## 敵

- 小片: 標準的な敵です。
- 針走り: 速く近づきます。
- 格子盾: 8回攻撃を受けるまで本体へ被害が通りません。
- 胞子体: 倒れると小型の敵2体へ一度だけ分かれます。

敵は色だけでなく、輪郭、内部線、移動の仕方で見分けられます。危険な予告は線と輪郭でも表示します。

## 得点と部品

敵を倒した得点、生存時間、残り耐久力、ボス撃破を合計します。部品は敗北時にも獲得でき、次の実装で研究に使います。
