# カコマレ ゲームルール

## 目的

中央のコアを守りながら、敵を倒して装置を育てます。通常ステージでは最後に現れるボスを倒すと防衛成功です。コアの耐久力が0になると防衛失敗です。ステージ3をクリアすると、制限時間のない無限モードを選べます。

## 操作

- 戦場を1本指で18px以上ドラッグすると、その方向を優先して狙います。
- 指を離してから標準設定では0.8秒後、「強い」自動照準補助では1.1秒後に自動照準へ戻ります。
- 強化候補は1回タップで選びます。
- パソコンではマウスのドラッグとクリックを使います。Escで一時停止できます。
- 画面を非表示にしたり回転したりすると戦闘は一時停止します。戻ったら再開カウントダウン後に続きます。

## 装置

初期装置は連針砲です。連針砲は単体への連続攻撃が得意です。強化候補から、光路刃、群集弾、反発輪、連鎖導体、周回刃、残響円盤、遠隔重力点を追加できます。新しい武器や補助装置を選ぶときは、候補カード内の空いている面を1回タップして装着します。補助装置は左右に接続した武器へ効果を与えます。武器はレベル3と5で発展分岐を選べます。

群集弾は指定位置まで飛び、着弾前に円形の予告を表示してから範囲攻撃を行います。残響円盤は敵に当たったときも進行方向を変えます。周回刃の外周型は、周回半径だけでなく刃の長さも伸びます。

回転冠は内側の停止位置へ着くと、コアへ向かう攻撃を予告して放ちます。予告線を見て、その方向の攻撃を止めるか、弾を壊してください。

## 敵

- 小片: 標準的な敵です。
- 針走り: 速く近づきます。
- 外殻: 一度に受ける被害を24までに抑えます。
- 格子盾: 8回攻撃を受けるまで本体へ被害が通りません。
- 胞子体: 倒れると小型の敵2体へ一度だけ分かれます。
- 標識体: 周囲の敵を速くします。
- 投下体: 離れた位置から遠隔弾を撃ちます。
- 位相体: 一定間隔で攻撃を受けなくなります。

敵は色だけでなく、輪郭、内部線、移動の仕方で見分けられます。観測環は外殻・標識体・投下体・位相体に有効です。危険な予告は線と輪郭でも表示します。

## 得点と部品

敵を倒した得点、生存時間、残り耐久力、ボス撃破を合計します。部品は敗北時にも獲得でき、ホームの「研究と記録」で使えます。研究ではコア、攻撃、強化候補、敵図鑑、武器記録、方向別被害を伸ばせます。

## 設定と保存

効果音、生成音楽、演出量、画面揺れ、動きを減らす設定、自動照準補助は端末内に保存されます。演出量は処理負荷に応じて自動的に下がることがあります。名前、進行、記録も外部へ送信せず端末内だけに保存します。
