# カコマレ ゲームルール

## 目的

中央のコアを守りながら、敵を倒して装置を育て、1プレイの得点を競います。「プレイする」から無限モードへ直接進みます。コアの耐久力が0になると終了です。通常ステージの攻略・解放・研究購入は必要ありません。

## 操作

- 戦場を1本指で18px以上ドラッグすると、その方向を優先して狙います。
- 指を離してから0.8秒後に自動照準へ戻ります。過去の照準補助設定による差はありません。
- 強化候補は1回タップで選びます。表示しただけでは経験値・レベル・装備は変わらず、候補と配置先の有効性を確認した選択確定時に1回だけ反映します。
- パソコンではマウスのドラッグとクリックを使います。Escで一時停止できます。
- 画面を非表示にしたり回転したりすると戦闘は一時停止します。戻ったら再開カウントダウン後に続きます。

## 装置

初期装置は連針砲です。連針砲は単体への連続攻撃が得意です。V5では基本武器50種類（既存8、最初の追加4、V4追加13、V5追加25）と補助20種類が戦闘登録され、分岐・レベル・発展形を別の基本武器として数えません。候補から出た武器や補助装置は、空いている面を1回タップして装着します。補助装置は接続した武器へ、威力・間隔・状態・防衛・配置など条件に応じた効果を与えます。武器はレベル3と5で発展分岐を選び、レベル8で一度だけ発展形を選べます。抽選到達、相乗効果の全件実戦、長時間本戦は後続の検証対象であり、登録数だけで公開受入済みとは扱いません。

除外回数を使い切っても、新しい装置は空いている面へ装着できます。面の位置は取得した順番で詰めず、選んだ場所を維持します。時計回りに、上から武器面1、補助面1、武器面2、補助面2、武器面3、補助面3です。一時停止の「装置を確認」でも空き面を含めて確認できます。

V4では分光弾、曲射砲、拘束索、脈動砲、散弾幕、固定杭、閃光弾、横断刃、導標弾、爆縮核、牽引槍、旋回渦、守護灯を追加しました。V5ではさらに扇裂砲、膨張弾、追跡針、穿孔錐、薄霧弾、火花連射、螺旋弾、開花弾、往復舟、吸収線、双映鏡、静止針、地脈槌、放射軸、虚空裂、絡網射、共鳴鐘、雷柱、霜結線、微群機、返照盾、潜航弾、軸旋砲、種弾、終奏砲を登録し、基本50種類へ到達しました。25種類を最終完成とは扱わないという履歴は、進行記録に残しています。

強化で配置層を開くと、第2層、第3層の武器面・補助面が順に使用可能になります。戦闘を停止している「装置を確認」では、同種の空き面への移設、同種の装置同士の入替を行えます。移設・入替ではレベルと発射待ち時間を保持し、戦闘中の無制限な切替は行いません。

武器・補助の面が埋まった後も、その種類の新しい装備が交換候補としてランダムに出ます。交換先の番号と元の装備を確認し、元Lv1/2は同じレベル、Lv3以上はLv3で新装備を置きます。武器はLv3の分岐を選び直し、元の分岐・照準強化・発展は持ち越しません。これは停止中の「場所だけの入替」と別の操作です。

配置見本は戦場と同じ向きで、内側・中側・外側の順に番号が増えます。武器は青の四角、補助は金色の丸と文字で区別します。補助の候補には配置先ごとの接続武器名を示し、詳細と一時停止画面で作用・条件・相乗効果を確認できます。除外は1プレイ共通2回で、残回数を表示します。除外するのはその候補であり、武器系統全体ではありません。

連針砲の拡散型は3方向へ弾を出し、各弾は最初の敵で消えます。貫通型は弾数を増やす代わりに同じ弾を複数の敵へ通します。盾の残り枚数と敵のHPは別表示です。

| 補助を置く場所 | 効果を受ける武器面 |
|---|---|
| 補助面1 | 武器面1・2 |
| 補助面2 | 武器面2・3 |
| 補助面3 | 武器面3・1 |

群集弾は指定位置まで飛び、着弾前に円形の予告を表示してから範囲攻撃を行います。残響円盤は敵に当たったときも進行方向を変えます。周回刃の外周型は、周回半径だけでなく刃の長さも伸びます。

群集弾の分裂型は、最初の範囲攻撃のあと3方向へ小弾を放ち、それぞれの着弾点で小さな範囲攻撃を行います。小弾は再分裂しません。残留型は着弾地点へ減速領域を残し、制動環が隣接していれば領域の減速時間も伸びます。反発輪の強反発型は押し戻し距離と一射の威力を増やし、制動環は押し戻し・減速時間へ適用されます。遠隔重力点でも制動環が隣接していれば領域内の減速時間を伸ばします。

回転冠は内側の停止位置へ着くと、コアへ向かう攻撃を予告して放ちます。予告線を見て、その方向の攻撃を止めるか、弾を壊してください。

回転冠の盾は、敵から見た攻撃の到来側に板があるときに被害を防ぎます。弾と反射光線は進行方向の反対側、連鎖は直前の敵から、範囲攻撃はその中心から当たる側を使います。周回刃は回転の接線方向から当たる側を使います。範囲攻撃の中心と敵の中心が重なる場合は方向を持たない攻撃として扱い、回転冠の方向付きの盾は防ぎません。位相体の無敵時間、格子盾の必要命中回数、外殻と回転冠の1回あたりの被害上限は別に適用します。

連鎖導体の終端破裂型は、連鎖が届いた最後の位置で破裂します。上下左右のどの方向でも同じ規則です。遠隔重力点の崩壊型は、領域の生成時に計算した攻撃力の1.8倍を終了時の範囲攻撃に使います。生成後の武器強化によって、すでに存在する領域の攻撃力は書き換わりません。

遠隔重力点による位置の吸引は、コアからの安全半径180の外側で行います。すでに半径180以内にいる敵は吸引で位置を動かさず、減速だけを適用します。ボスも位置を動かさず減速だけを受けます。吸引先を通り越したり、安全半径より内側へ押し込んだりすることはありません。

## 敵

- 小片: 標準的な敵です。
- 針走り: 速く近づきます。
- 外殻: 一度に受ける被害を24までに抑えます。
- 格子盾: 8回攻撃を受けるまで本体へ被害が通りません。
- 胞子体: 倒れると小型の敵2体へ一度だけ分かれます。
- 標識体: 周囲の敵を速くします。
- 投下体: 離れた位置で発射前の予告を出してから遠隔弾を撃ちます。
- 位相体: 一定間隔で攻撃を受けなくなります。
- 突進体: 予告後に短く突進し、突進後に隙があります。
- 護衛体: 限定方向の盾で近くの敵を守ります。
- 修復体: 予告後、近くの敵を少量だけ回復します。
- 造兵体: 小型の召喚体を最大4体まで作ります。召喚体から経験値・得点は出ません。

敵は色だけでなく、輪郭、内部線、移動の仕方で見分けられます。観測環は外殻・標識体・投下体・位相体に有効です。危険な予告は線と輪郭でも表示します。戦闘が進むと、外周の光った方向から3体の集中波が来るため、その方向を先に照準できます。

## 得点と成長

得点は討伐・危険段階・ボス・挑戦達成の台帳から一度ずつ加算します。生存時間や残り耐久力を追加得点にはしません。毎回同じ初期能力で始まり、過去の研究や部品による有利不利はありません。

戦闘画面は開始からの経過秒数を表示します。強化中、配置確認中、構成変更中は、戦闘時間、敵、弾、被害、攻撃間隔、出現処理、危険予告を完全に停止します。候補の説明と変更値を読んでから選べるようにし、再開時は照準入力を解除します。現在レベル、経験値残高、未選択の強化回数は別々に表示します。

通常候補が少ない場合も兵装研磨・追加外装・攻守補強で不足分を補い、3枚の有効候補を提示します。攻守補強はコア最大/現在耐久+1と全武器の基準威力+1%です。部品だけを受け取る候補は無限には出しません。

複数回分の経験値があるときは連続して選べますが、3回選択後に続けるか残りを保留して戦闘へ戻るかを選べます。保留した後は敵を倒しても強化画面は自動では開きません。戦闘画面の「強化を選ぶ（n回）」から、追加の撃破を待たずに残りを選べます。残りを使い切ると、次のレベルアップは通常どおり自動で開きます。強化中に画面を離れたり回転したりした場合は、同じ候補から再開します。通常の強化確定後は毎回3秒のカウントダウンを挟みません。

結果画面では得点と再戦・共有・ホームを先に表示し、主にダメージを与えた武器上位3種類と使用補助名を確認できます。個体番号、方向別被害、全強化履歴、未使用装備の一覧は表示しません。検証用の内部記録は保持します。

## 設定と保存

効果音、生成音楽、演出量、画面揺れ、動きを減らす設定と名前は端末内に保存されます。演出量は処理負荷に応じて自動的に下がることがあります。設定に保存データ管理の操作はありませんが、旧進行や記録を削除することはありません。結果はランキング接続が明示的に設定された場合だけ、開始受付の識別子とサーバー発行のプレイ識別子を使って送信します。本番受付は未設定です。接続できなくても結果・再戦・ホーム操作は失われません。

戦闘途中の保存は、固定更新の安全な境界で、敵・弾・候補・保留強化・配置・容量・乱数・入力台帳をまとめて保存します。ブラウザを閉じた後はホームの「中断したプレイを再開」から同じ状態を再開します。通常の進行保存（v3）と途中状態、結果の一回精算は別の台帳として扱い、古い保存を読み込めない場合に初期化しません。

演出量が少ない・最小になっても、敵と敵弾の位置は表示します。負荷を下げるために粒や装飾、被害数字などを減らし、表示設定によって被害や得点の計算を変えません。

50武器・20補助の登録と、元計画の全固有動作が完成していることは別です。現在の名称・効果は [武器一覧](WEAPON_CATALOG.md) と [補助一覧](SUPPORT_CATALOG.md)、未達は [監査記録](ENDLESS_USABILITY_REVIEW.md) を参照してください。
