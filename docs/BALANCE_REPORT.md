# V6へ引き継いだ設計判断と未測定範囲

V1で定めた基本50武器・補助S・相乗効果・競技条件をV6へ引き継ぎました。V5でruntime登録されたこと、V6でゲーム側の保存・結果・送信準備ができたことと、バランス・競技受入・本番連携が完了したことを混同しません。

## 決定表

| ID | 引き継いだ判断 | 根拠 | 後続で測ること |
|---|---|---|---|
| D01 | 基本50（既存8＋追加4＋V4追加13＋V5追加25）、補助S=20 | 役割の重複比較と50×20の適用表を同時に埋め、名前だけの登録を防ぐ | 抽選到達・実戦相乗効果・重複監査 |
| D02 | 通常Lv8、Lv3/Lv5分岐、Lv8特別発展を共通の出発点にする | 通常成長だけでも価値を残し、発展を特定補助の当選に依存させない | V3以後の成長間隔・同時発展数・派生上限 |
| D03 | 初期容量6、武器3枠・補助3枠、拡張は候補から選ぶ | 18枠を全て最大化することと設置場所を増やすことを分離する | V2/V3の容量不足・万能化・選択不能 |
| D04 | 新規武器3、既存成長5、補助4、拡張2、特別1、継続1 | 有効候補を残し、登録数の多い種類だけが占有しない | V5の提示率、停滞、引き直し、方針別分布 |
| D05 | 撃破10、危険段階100、ボス1,000、追加危険250 | 生存秒・残HPを主得点にせず、実際の対処を一度だけ評価する | V6前の稼ぎ行動、同点、整数範囲、終了種別 |
| D06 | 予告0.9秒以上、敵・弾・派生の共通上限、5分節目 | 見えない即死と無制限増殖を避け、局面差を作る | 各敵の撃破時間、経験値、危険段階、負荷 |
| D07 | ルール版・play_id・submission_idを分け、ゲーム側は既定未接続で再送契約を準備 | 文書上の契約名と本番の実署名を混同しない | V6の実験場受付、再送、版拒否、上位再計算 |

## まだ測っていないこと

- 50武器を実戦へ追加した後の撃破時間、取得率、弱点、処理負荷は未測定です。
- 20補助の実効値、1,000組の長時間相乗効果、容量による選択差は未測定です。
- 通常720試行、競技無限60試行、30/60/120回描画比較、iPhone Safari実機はV2〜V7の対象です。
- 採用案は設計契約であり、実測で変更する場合はルール版を分け、既存記録を上書きしません。

## 受入条件

V6では、V5の内容実装に加えて、保存v3／安全境界の途中状態、結果一回精算、ゲーム側ランキングアダプター、manifest、結果画面の送信状態を提出します。これだけで長時間本戦、iPhone Safari、本番ランキングが公開された、バランスが完成したとは報告しません。
