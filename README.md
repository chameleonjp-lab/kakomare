# カコマレ

「カコマレ」は、六方向から迫る敵を防ぎながら、六角形の装置を組み上げるブラウザ防衛ゲームです。

## 初めて遊ぶ方へ

中央のコアを守り、敵を倒して装置を育てながら高得点を目指します。コアの耐久力が0になると終了です。制限時間はなく、新しいプレイには前回の装備を持ち越しません。

- 攻撃は自動です。戦場を1本指でドラッグすると、その方向を一時的に優先して狙えます。
- 敵を倒して経験値をためると3つの強化候補が出ます。選択中は戦闘が止まるので、武器や補助の配置を考えて選びます。
- 補助装置は線でつながる武器を支援します。火力だけでなく、配置と危険な敵への照準が攻略の要点です。
- 結果をオンラインランキングへ送信する実装があります。通信の状態はゲーム内表示を確認してください。

ブラウザ向けのゲームです。公開版の配信状況は下の公開手順と区別し、手元で試す場合は次の開発手順で起動し、表示されたローカルURLを開いてください。

画面中央のコアは動きません。「プレイする」から制限時間のない無限モードへ直接進み、1プレイの得点を競います。装置が自動で攻撃するため、危険な方向をドラッグして短時間だけ手動照準し、ランダムな強化候補から選びます。装備の配置・交換は番号付きの見本で確認できます。画面を拡大する二重タップ、長押し、ピンチはゲーム操作に使いません。

## 開発

```bash
npm ci
npm run dev
```

検査は次でまとめて実行します。

```bash
npm run check
```

## 公開

GitHub Pagesの公開パスは `/kakomare/` です。`main`へのpush、または`main`を対象にした手動実行だけが公開処理を起動します。Pull Requestでは品質検査だけを実行し、公開前にも同じ検査を再実行します。

公開前の静的ファイル、favicon、OGP画像、公開サブパスは `npm run verify:dist` で確認します。公開後のiPhone Safari確認は [公開確認手順](docs/RELEASE_CHECKLIST.md) の順番で行います。

ゲーム画面は画像素材に依存せず、Phaserの図形描画とWeb Audio APIで生成します。名前・設定・途中状態を端末へ保存し、旧進行データも保持しますが、研究・記録・保存データ管理の画面は表示しません。無限モードの結果は、カメレオンJPの実験場へSupabaseの公開キーだけを使って送信します。送信の詳細は [本番公開・ランキング連携記録](docs/PRODUCTION_RELEASE.md) にまとめています。
